# Tokeru 3.4.0

2026-10-23。3.4 的核心是把「原卷」和「答题卡」彻底分开，并重做题库、速查、标签、导入和 AI 测试。3.2/3.3 的题库筛选、考试三栏、自动分图、排版字体、侧栏收起、便携包等能力保留。

## 1. 原卷与答题卡

- 新增共享组件 `src/components/PaperView.tsx` 与 `src/styles/paper.css`，考试页、题库详细模式、速查详细模式共用同一套原卷排版。
- **材料强相关题不再拆成逐题卡**：完形、听写、填空（以及带 material 的听力/阅读题组）只渲染一次材料、一次词库，题目作为材料内的连续题组；阅读 short_answer 等有独立题干的题仍逐题显示。
- 考试页仍保持三栏：左答题进度、中原卷、右答题卡。原卷负责阅读与定位，答题卡负责作答，两者不再混在一起。
- 题库「详细」为原卷；「简要」为紧凑题目列表，点击题卡再加入选题篮。
- 速查「详细」为原卷 + 每题浅色答案/解析附注；「简要」为分区题目列表，点击展开完整题干、选项、答案和标签编辑。
- 深链 `?q=<questionId>` 仍可滚动定位并高亮。

## 2. 标签栏

- 新增 `tag_groups`、`tag_assignments` 两张表，固定三栏：**学科 / 题型 / 难度**，可新建自定义栏、重命名、删除。
- 题库左侧栏按栏分组；详细模式显示「学科：数学」这类带栏名前缀的标签，简要模式显示裸标签。
- 「管理标签」打开 `TagBoard`：原生拖放把标签拖入栏，支持新增/删除栏；删除栏后标签回到「未归类」，不会丢标签。
- 新增 AI 整理：`ai_organize_tags` 让模型按现有标签栏给建议，前端先预览再点「应用 N 条」，不会自动改库。
- 标签颜色使用主题令牌（violet/teal/amber/rose/slate），不把颜色写死到数据库。

## 3. AI 测试、清洗与整理

- 设置页「测试连接」「测试视觉模型」直接使用**当前表单里尚未保存的** API 地址、模型、Key；不再依赖已保存配置和某道题。成功提示显示实际模型与耗时，失败显示后端真实错误。
- 新增 `ai_test`、`ai_complete` 命令；AI 调用统一走 `ai::post_chat`，文本/视觉共用同一套 OpenAI 兼容请求。
- 导入页支持「应用内 AI 清洗」：材料不规范时把原始材料交给 `ai_complete`，去掉代码围栏后直接进入预览；也可选择重新上传或复制提示词自行清洗。
- AI 标签整理只产生建议，应用前必须人工确认。

## 4. 导入重构

- 步骤 1 支持拖入/选择 **PDF / Markdown / TXT / JSON**，也支持直接粘贴按 Markdown 规范写的文字。
- 材料窗口旁常驻「复制提示词」按钮，不再需要先进入下一步才能复制。
- 本地检查材料：有明确题号/分区/答案/JSON 结构才认为规范；不规范时给出三条路：重新上传、应用内 AI 清洗、复制提示词。
- 预览、确认导入、撤销批次、文件夹、试卷标签、题目标签、题目图片全部保留。

## 5. 删除试卷与启动修复

- 题库试卷卡「更多」菜单新增「删除试卷」；确认框明确说明会同时删除该卷的作答记录、练习记录、错题和导入批次。后端 `delete_set` 在事务里按顺序清理。
- `src-tauri/src/main.rs` 第 1 行加入 `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]`；release 安装版/便携版双击只开 Tokeru 窗口，不再附带控制台终端。debug 模式仍保留控制台，属预期。

## 8. 安装器非交互验证

本轮按用户要求**不点击安装窗口**。验证方式：

1. 先运行已安装的 3.3 版 Tokeru；
2. 把 3.4.0 安装包复制到 ASCII 临时路径，用 `/S` 静默安装（不点击、不按键）；
3. 安装器的 `NSIS_HOOK_PREINSTALL` 调用 `taskkill /F /IM tokero.exe`，等待后删除旧 exe，再写入 3.4.0；
4. 结果：旧 Tokeru 进程退出，`%LOCALAPPDATA%\Tokeru\tokero.exe` 为 3.4.0，`uninstall.exe` 时间戳更新，注册表 `DisplayVersion=3.4.0`。

说明：本机通过中文项目路径用 `cmd start`/`Start-Process` 启动安装器时进程未创建，复制到 ASCII 临时路径后正常；这是测试启动方式/路径编码问题，不是安装器逻辑。安装包未签名，Windows 仍可能提示未知发布者。

## 9. 已知限制

- 自动分图的真实视觉模型未在本轮验收；3.3 的链路与 mock 验证保留。
- 题库详细模式中，合并后的材料题组没有逐题选择圈，可用「全选本卷/分区全选」或切到简要模式逐题选。
- 速查/题库在 1024px 宽度下左侧题号栏会变成横向条，内部可横向滚动。
- 导入 AI 清洗依赖模型输出，复杂版式/扫描件仍可能失败；失败时保留「重新上传/复制提示词」两条退路。
- 自定义字体只支持 Windows 系统字体枚举；大字体文件只在当前会话生效。
- 安装包未签名；WebView2 采用 skip 模式，系统缺失时需用户自行安装 Runtime。
